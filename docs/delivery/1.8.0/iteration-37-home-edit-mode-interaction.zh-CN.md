# 迭代 37：Home 编辑模式交互

> 适用版本契约：[1.8.0 交付](delivery.zh-CN.md)。本契约只定义范围，不授权实现、提交、推送、打 tag 或发布。

## 目标

交付修订后的 Home 编辑模式交互，含模块标题及其与既有编辑操作的关系，但不引入模块折叠。

## 产品与版本引用

- 产品契约基线：`0e6ac891f26f0d7ea5d4e483d4d0916a99de23b6`
- 适用产品文档：[Home 行为](../../product/surfaces/home.zh-CN.md)、[Home 呈现](../../product/presentation/home.zh-CN.md)、[导航](../../product/navigation.zh-CN.md)、[Home 底部应用栏](../../product/features/home-bottom-app-bar.zh-CN.md)
- 适用版本契约：[1.8.0 交付](delivery.zh-CN.md)
- 所有产品文档链接均按产品契约基线 `0e6ac891f26f0d7ea5d4e483d4d0916a99de23b6` 阅读。

## 可观察结果

作者可以通过契约规定的目标进入、使用和退出 Home 编辑模式，看到承担已定义职责的模块标题，并完成既有编辑操作，不产生含义不清或重复的目标。

## 纳入工作

- 模块标题呈现及其与编辑模式入口的关系。
- 当前契约覆盖的、通过绑定的基本信息快捷操作进入的编辑模式进入、退出、Back、手势、目标与恢复行为。
- 负向边界：普通 Home 空白区域、时间/日期区域、收藏内容区以及 Loading/Error/Retry 区域不产生额外的编辑模式入口。
- 与迭代 36 底部应用栏边界的集成。
- 双语资源、导航、呈现、线框与聚焦测试。

## 排除工作

- 模块折叠或展开、折叠列表持久化及标题触发折叠。
- 新的收藏放置规则或 Flow 布局。
- 当前产品文档未定义的新编辑模式能力。

## 技术变更面

Home 编辑模式状态与协调、模块标题、导航、无障碍语义、资源与测试。

## 依赖与顺序

本迭代跟随迭代 36，并建立迭代 38 使用的交互边界。

## 迁移与兼容影响

既有 Home 内容与收藏状态保持不变。缺失的呈现状态遵循当前契约默认值。

## 安全、隐私、权限与许可影响

不引入新权限、网络、账户或外部服务。

## 风险与未决决策

模块标题不得暗示模块可以折叠。编辑模式目标必须与底部应用栏目标及普通内容手势保持区分。

## 验收标准

- 模块标题符合已定义呈现职责，不暗示折叠。
- 绑定的基本信息入口可以进入编辑模式；普通空白、时间/日期、收藏、Loading、Error 与 Retry 区域不能进入编辑模式。
- 进入、退出、Back 与恢复行为符合契约。
- 既有编辑操作仍可到达且含义明确。
- 不引入折叠列表状态或持久化。

## 验证要求

在主设备验证绑定的基本信息入口、负向入口边界、编辑模式进出、Back、进程重建、模块标题呈现、底部应用栏交互、无障碍遍历与普通 Home 手势。
