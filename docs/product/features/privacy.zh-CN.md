本文定义 Launcher4Max 当前面向用户展示的 Privacy 正文，以及锁屏能力以启用为目的跳转前单独展示的显著披露。本文描述当前产品契约，不构成法律结论、商店审核通过结论或实现已经完成的声明。

Privacy 正文与显著披露是两个独立展示。展示或阅读 Privacy 不表示用户已经同意无障碍访问。显著披露在正常的锁屏启用流程中出现，并且紧邻 Launcher4Max 提供打开 Android 无障碍设置操作之前。

两个展示都随应用本地提供并可离线阅读，根据系统语言选择英文或简体中文资源，不支持的语言回退为英文。应用不得从 GitHub 或其他网络来源获取这两份正文。

## 面向用户的 Privacy 正文

### Privacy

Launcher4Max 的当前产品数据和处理均以保留在你的设备上为设计原则。

### 在设备上使用的信息

Launcher4Max 会处理 Android 在当前 Launcher 角色和权限边界内向其暴露的应用条目，其中可能包括应用名称、图标、可启动组件、Android profile 身份、平台提供的 badge 和应用快捷操作。Launcher4Max 使用这些信息展示应用、区分可启动身份、启动你选择的条目，以及展示适用的快捷操作。

当你添加 Home 收藏时，Launcher4Max 会在设备本地保存该可启动身份、所属模块及顺序，同时保存模块类型、每个模块的名称与名称是否展示，以及适用的纵向模块图标尺寸、名称（文字）尺寸、名称位置和每行数量。临时的最近一次移除撤销快照可以保存最近一次被移除的收藏或最近一次被整列取消收藏的模块，但仅持续至 Snackbar 被替换、消失或被已定义的生命周期作废；它不会作为撤销历史保存。因此，移除模块中最后一个收藏时，快照可以保留恢复该收藏及其原位置所需的模块数据。整列取消收藏时，快照保留一次恢复该模块所需的模块数据。Launcher4Max 不提供独立的持久模块移除历史。不属于已保存收藏的应用清单及快捷操作信息仅按需处理，不会作为 Launcher4Max 自有的应用使用历史保存。

Launcher4Max 会在设备本地保存你选择的 Drawer 应用图标尺寸、应用名称尺寸、名称位置、每行条目数量、分组锚点表现，以及背景不透明度百分比。这些显示设置只用于恢复你选择的呈现，不属于应用使用历史。

Launcher4Max 还会读取界面与控制功能所需的当前系统信息，包括时间、日期、系统语言、默认 Launcher 状态，以及可选 Launcher4Max 无障碍服务是否已经启用并连接。时间和日期不会作为历史记录保存，这些系统状态也不会用于行为分析。

### 存储、备份与删除

收藏（包括哪些收藏放在主页底部常驻应用栏，以及该应用栏的开启、固定和图标大小设置）、Drawer 显示设置、快捷操作绑定和图标形状偏好保留在设备上，直到你进行变更或 Android 清除 Launcher4Max 的应用数据。图标形状偏好包括剪裁模式和已保存的自定义圆角比例。Launcher4Max 为这些数据提供手动本地备份与恢复。备份会把包含你当前收藏、主页底部常驻应用栏的位置与设置、Drawer 显示设置、快捷操作绑定和图标形状偏好的一个 JSON 文件写入你在系统文档选择器中选定的位置；该文件始终由你掌控，永不上传。恢复会读取你选择的备份文件，并在你明确确认后，以一次原子操作替换当前的收藏、应用栏位置与设置、显示设置、绑定和图标形状偏好。Launcher4Max 不提供应用内一键清空、自动备份、云同步、云备份或设备到设备的数据迁移。根据当前产品契约，必须继续为 Launcher4Max 自有收藏与显示设置数据禁用 Android 云备份和设备迁移备份。

Launcher4Max 还会保存一项非内容偏好：你关闭 Home 默认启动器提示的本地日期，使该提示在当天余下时间内保持关闭。它属于用户可控的呈现状态，不属于应用使用历史，也不包含在备份文件中。

一次性启用当前 Home 模块模型时，Home 收藏从空状态开始，不迁移原收藏结构。这项由作者接受的产品转换不会清除独立的 Drawer 显示设置或其他无关本地配置。

如果已保存收藏数据无法可靠读取，Launcher4Max 会保留原始不可读数据并禁止收藏变更，而不是静默替换为空列表。你可以重新尝试读取。通过 Android 系统设置清除 Launcher4Max 应用数据或卸载 Launcher4Max，会移除其本地保存的应用数据；当前产品此后不提供恢复功能。

### 数据收集、共享与网络使用

Launcher4Max 不提供账号、广告、分析、崩溃报告上传、云服务或 Launcher4Max 运营的服务器。Launcher4Max 不会传输、出售或共享上述在本地处理的信息。Home、Drawer、应用启动和 Settings 核心功能在没有网络连接时仍然可用。

点击 GitHub 链接时，Launcher4Max 会请求 Android 使用系统浏览器或其他兼容应用打开固定 URL。Launcher4Max 只把该 URL 交给所选处理程序；外部应用及其使用的网络服务遵循其各自的隐私规则。

### 锁屏与无障碍访问

锁屏是可选功能。只有你把某个 Home 快捷操作槽位绑定为锁屏，并在 Android 系统设置中启用 Launcher4Max 用途受限的无障碍服务后，该功能才会生效。Launcher4Max 仅在你于 Home 中符合条件的空白位置执行已绑定的手势后，使用该服务请求一次系统锁屏操作。

该服务不读取屏幕或窗口内容，不检查其他应用界面，不为分析收集无障碍事件，不观察应用使用情况，不执行后台自动化操作，也不发送或共享数据。除用户明确请求的锁屏外，它不执行其他全局操作。Launcher4Max 不使用设备管理员作为回退方式。你可以随时在 Android 无障碍设置中关闭该服务，而不影响其他独立 Launcher 功能。

### 权限与 Profile 边界

Launcher4Max 只使用当前产品契约所需的 Android 能力。它不申请 `ACCESS_HIDDEN_PROFILES`，不访问或展示必须依赖该权限的 Android Private Space 条目，也不提供 Private Space 管理能力。Android 在 Launcher4Max 当前角色和最小权限边界内暴露普通、工作资料及应用分身条目时，这些条目可以显示。

### 联系方式

如有隐私问题，请打开 Launcher4Max GitHub Issues 页面：

`https://github.com/max-archer-m/launcher-4-max/issues`

点击该地址时使用隐式系统浏览器操作。如果没有兼容的处理程序能够打开，Launcher4Max 显示本地化短提示 `无法打开隐私联系页面`，并保持 Privacy 展示不变。

## 锁屏显著披露

以下披露在以启用为目的跳转 Android 无障碍设置之前单独展示，不得合并到 Privacy Bottom Sheet 或其他无关披露中。

### 标题

`锁屏的无障碍访问`

### 正文

`Launcher4Max 仅使用 Android 无障碍服务，在你于 Home 中符合条件的空白位置执行已绑定的快捷操作手势时锁定屏幕。该服务不访问或收集个人或敏感数据，不读取屏幕或窗口内容，不观察其他应用中的活动，不收集无障碍事件，也不发送或共享数据。锁屏是可选功能，你可以随时在 Android 设置中关闭该服务，而不会影响其他 Launcher 功能。`

### 操作

- `取消`：关闭披露并停留在 Launcher4Max，不打开系统设置。
- `同意并继续`：不保存同意历史，只确认本次跳转 Android 无障碍设置。服务是否启用仍以 Android 状态为准。
- 通过 Back、遮罩操作或其他取消路径关闭披露不构成同意，也不打开系统设置。
