# 样式设置面板表现规范

> 英文公共语义源：[style-settings-panel.md](style-settings-panel.md)。

## 职责

本文是 Drawer 与 Home 样式设置面板共用视觉表面、设置行、选择器、步进控件和应用尺寸控件的唯一表现来源。[Drawer 表现](drawer.zh-CN.md#显示设置)与 [Home 表现](home.zh-CN.md#编辑坞与样式设置面板)只负责各自宿主特有的位置、模态性、高度、内容和周围布局；对应行为规范继续负责状态与操作结果。

这项共享产品契约要求两处呈现为可观察的一致面板样式，但不规定源码类、框架抽象或实现组件边界。

## 共享面板表面

- 样式设置面板使用一套资源化的 `darkSurfaceBaseColor` 深色表面、准确 `12dp` 圆角。Drawer 与 Home 使用相同的表面颜色、圆角半径、水平外边距和边框，不得按宿主替换为另一套视觉值。
- 面板边缘处理为一圈 `1dp` 的 `#6E6E73` 边框，沿面板圆角绘制。以上为作者于 2026-09-09 接受的当前交付值；设备对比可通过作者接受并更新本规范予以修订。
- 面板表面不设置整体容器 padding。每个设置块由一个不可交互的标题行和一个内容行组成。标题行准确高 `32dp`；标准内容行准确高 `48dp`，应用尺寸块为已接受的 `56dp` 例外。各行占据面板完整内部宽度，使用起止各 `12dp` 的内容 inset，并使内部内容垂直居中。只读信息行（例如选择提示或固定样式说明）为单一 `48dp` 行。
- 各宿主自行决定其设置块顺序。
- 共享面板表面本身不定义 Scrim、模态输入阻断、点击外部关闭、底部外边距、最大高度、内部滚动或与其他控件的衔接方式；这些规则由各宿主分别负责。

## 共享选择器与控件

- 属于同一个语义设置的关联控件共同出现在一个内容行；例如"应用排列"块把名称位置选择器和每行数量步进控件合并在一个内容行。只有当控件溢出可用行宽时，内容行才可以横向滚动；标题行从不滚动。契约验收要求为：在作者指定的基线设备（当前为作者指定的主物理设备；Pixel 8 暂不考虑）上内容行不溢出。
- 面板内的交互目标至少为 `40dp x 40dp`。这是对共享 `48dp` 最小目标的作者批准例外，因为面板不属于频繁触控区域，且紧凑的 `48dp` 内容行否则没有目标余量。可见控件尺寸不决定命中几何。
- 紧凑双选项选择器使用 `140dp x 40dp` 深色圆角外框、浅色边框和 `2dp` 内部 padding，包含两个等宽的 `68dp x 36dp` 浅色填充、无边框圆角滑块。居中选项文字使用中等字重的共享 `secondaryTextFontSize` 及对应行高。每个选项保留至少 `40dp` 高、占满滑块宽度的目标。
- 选择器滑块和文字颜色转换使用同一个平台或主题短时长属性动画 token，以约 `200ms` 作为参考时长，不硬编码时长。
- 减少与增加控件使用本地化文字，显示在约 `28dp x 28dp`、圆角 `4dp` 的可见背景上；每行条目数量使用约 `32dp x 28dp` 的可见背景。三个控件各自保留至少 `40dp x 40dp` 的交互目标；可见背景尺寸不决定命中几何。
- 应用尺寸块在其已接受的 `56dp` 内容行上组合两个三档收缩滑杆，沿用共享的起止各 `12dp` 内容 inset，两滑杆之间间距为 `16dp`。两个滑杆等分剩余行宽：物理左侧滑杆选择应用图标尺寸，物理右侧滑杆选择应用名称（文字）尺寸。这是一个由本规范完整拥有的自定义控件，不是平台标准滑杆。
- 每个滑杆绘制一个直角三角形轨道剪影：底边水平，左端为垂直高边，上斜边自左向右线性下降至右端，任意位置的高度自左向右递减。三个吸附位分别位于左端、水平中点与右端，各档位的剪影高度按大、中、小依次递减。thumb 左侧的轨道部分与 thumb 使用共享 `primaryTextColor`；thumb 右侧的轨道部分使用共享 `secondaryTextColor` 处理，不引入任何新的颜色 token。
- 一个竖直 bar 形拖动柄位于轨道上所选吸附位处，其位置单独表达当前档位：控件不显示当前档位文字，也没有其他指示元素。作者于 2026-09-21 接受的校准值为：轨道左端与右端高度分别为 `20dp`、`8dp`；thumb 高 `40dp`、宽 `4dp`、圆角 `2dp`；轨道在 thumb 两侧各留出 `6dp` 间隙。
- 每个滑杆暴露本地化标签——物理左侧滑杆为应用大小、物理右侧滑杆为文字大小——当前档位名称，以及标准本地化范围操作，每次移动一档；被宿主行为禁用的滑杆报告不可用，且不改变档位。交互语义——预览、提交、震动与条件启用——由各宿主行为规范负责。
- 背景块在其 `48dp` 内容行上组合一个百分比读数和一个平台标准连续 progress 滑杆，沿用共享的起止各 `12dp` 内容 inset。读数位于物理左侧的一个固定宽度预留内，预留宽度以完整最宽值 `100%` 计量，使滑杆几何在所有数值下保持恒定；文本在预留内居中对齐。读数与滑杆之间间距为 `16dp`。滑杆占满剩余行宽，交互目标占满内容行整高，暴露 `0`–`100` 的连续百分比范围，不显示刻度点。
- 读数以一条本地化格式串显示当前整数百分比，拖动期间实时更新，且为只读：它不是交互目标，也不暴露独立焦点目标。其文本使用常规字重的共享 `secondaryTextFontSize` 及其行高，颜色为 `primaryTextColor`。
- 滑杆活动轨道与拖动柄使用共享 `primaryTextColor` 作为唯一强调色；非活动轨道使用共享 `secondaryTextColor` 处理，不引入任何新的颜色 token。无障碍播报当前百分比值。
- 启用、选中、禁用、焦点、Ripple、文字和图标表现遵循[设计基础](../design-foundations.zh-CN.md)。保存、选择动画等临时操作锁定保留控件颜色和不透明度，同时拒绝激活并暴露禁用语义，不使选择器、数值或原本可用的步进操作置灰。处于数量边界的步进操作保留共享禁用透明度。宿主可以省略不适用的设置块，但不得重新设计共享行，也不得在对应行为契约没有要求时显示禁用占位。
